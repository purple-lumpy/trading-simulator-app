# 本地模拟行情标注

默认进入“决策标注”，顶部可以切回原版行情演示。

- 首次生成 600 根 5 分钟随机模拟行情，品种记为 SAMPLE，避免误认为是真实市场价格。
- 行情、标记和回放位置一起保存在当前浏览器、当前源的 localStorage 中。刷新、关闭重开、切换工作模式后继续使用同一份行情。不同端口的浏览器存储互不共享。
- 初始展示 40 根作为观察上下文。Next/Prev 控制回放；暂停后对最后一根已收盘 K 线标注。
- 每根 K 线一个决策：买入、卖出或观望。买卖数量大于零，观望数量为零。参考价取对应 K 线收盘价；初始持仓为零，前后仓位自动计算。不包含资金或实际订单成交。
- 列表支持定位、编辑和删除。历史操作改变后重算所有后续仓位，导致超卖的修改会被拒绝。
- 买卖标记显示在图表中；观望显示在列表中。后退回放不会删除已保存的标记，图表只绘制已经显示的 K 线对应的买卖点。
- “导出行情与标记 JSON”下载文件到电脑，包含 schemaVersion、dataset、markers、revealedCount。“恢复 JSON”校验后替换工作区。导入前请导出需要保留的数据。
- 浏览器存储不代替磁盘备份。清理站点数据可能丢失记录；存储失败会提示导出备份。损坏的已有存储不会被自动覆盖。

标注逻辑测试（Node.js 22.6+）：

```powershell
npm.cmd run test --workspace=simulator-app
```

目前回放和数据都在浏览器中，标记列表也保留历史决策，适合个人标注，不提供防作弊机制。
